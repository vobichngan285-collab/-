保益悦听语音组件只读调查工具 · 实验 1
适用：Windows 10/11 64 位，电脑上已安装保益悦听

目的：确定实际运行的保益进程、已加载语音 DLL、安装目录中可见的相关引擎文件。
这不是语音引擎，更不会修改游戏文字助手、保益悦听或广荣 TTS。

使用方法
1. 先启动电脑上的保益悦听，保持你平常使用的广荣微软语音音色，不必修改任何设置。
2. 将本压缩包解压到新文件夹，双击 BaoYiVoiceInspector.exe。
3. 使用保益读屏找到“开始只读扫描”，按回车。通常数秒内完成。
4. 找到“复制调查报告”，点击后回到 ChatGPT 粘贴内容；也可按“另存报告 TXT”后上传。
5. 如提示某些进程模块无法读取，属于 Windows 访问权限限制，先直接把现有报告给我分析即可。无需关闭保益，也无需额外安装语音包。

隐私与安全边界
- 工具不需要管理员权限，不联网、不上传，不发送朗读或停止命令，不注入 DLL，不更改注册表。
- 只读取进程名、已加载 DLL 名、相关安装目录和文件名、产品版本，以及与保益匹配的窗口所属进程 ID。
- 不保存窗口标题、界面文字、OCR 截图、聊天内容、语音音频、注册表中的密钥/许可证或配置文件内容。
- 报告中的用户文件夹、AppData、Temp 路径会做替换隐藏；仍请发送前浏览一下报告，删掉任何不想分享的程序名。
- 只在你点击“另存报告 TXT”时写入你指定的路径；“复制报告”仅使用系统剪贴板。
- 不需要安装 .NET 额外组件，Windows 10/11 通常已经具备 .NET Framework 4.x。
- Windows SmartScreen 可能对未经商业代码签名的小工具显示未知发布者；如果有疑虑，可先不运行。

注意事项
- CI 自动验证的是工具能在 Windows 启动、识别模拟进程并生成报告；CI 电脑没有你的保益悦听。
- 发现 grtts 或 NeuralVoice 文件，仅代表“存在”；只有某个进程的“已加载”记录才表明该文件当时在内存中。
- 即使发现已加载语音 DLL，也不能单凭这个结果确定它正用于你所听到的音色。下一步需要依据报告分析。
- 这个实验只用于调研。游戏文字助手仍保持 V1.6，之前第二档 OCR 十几秒和边角漏字不在本次修改范围内。
