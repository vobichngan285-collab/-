# 蓝星 OCR · 单引擎快速版 (Windows 11)

**唯一目标：快。** 只使用蓝星原始 PP-OCRv6 Small DET/REC 模型与 RapidOCR 推理。软件启动时预热一次模型；全屏、鼠标跟随、区域跟踪共用唯一引擎，模式切换不重新加载。

- **F8**：取按键时当前前台焦点窗口的可见桌面画面，识别完成叮声，鼠标指向逐行朗读；不记忆游戏窗口，不使用 GDI 窗口缓存。
- **F9**：在默认、鼠标跟随、区域跟踪三模式间切换。
- **F11**：画框，OCR 输入只有框内像素（鼠标模式为随光标移动的相对框，固定区域为屏幕绝对坐标）。
- **F7**：区域边框显示/隐藏，保留手动状态。
- **自定义扫描周期**：鼠标模式和固定区域各自支持 100–60000 毫秒，固定区域支持画面变化触发或周期触发。
- **OCR 性能设置**：2 / 4 / 6 线程；GPU DirectML 开/关；更改后下次启动生效。GPU 不可用时使用 CPU。
- **文本过滤**：英文、数字、符号、单独一个汉字（独立 OCR 行），只影响朗读，不修改原始坐标/文字。
- **已移除 Luna 的 OCR 运行链路**：不含完整 LunaTranslator Qt 程序、OCR 截图 DLL、IPC 接口和第二套识别模型。
- **语音保护**：为兼容已安装微软自然语音，保留唯一必要的 LunaSubprocess64.exe 原版语音辅助程序和 GPL 对应源码归档；它不是 OCR 引擎。

使用 GitHub Actions 的「Blue Star Fast Single Engine」运行成功后下载 artifacts 中的 ZIP。请安装到新的目录，**不要覆盖已验证的旧版**。目前还需要在你的电脑上实际比较《七日杀》的 OCR 准确率、首次响应和游戏 FPS。没有上传私有语音许可证、截图或游戏文字。
