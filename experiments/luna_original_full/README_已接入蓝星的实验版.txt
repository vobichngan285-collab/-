蓝星 Windows 游戏 OCR —— LunaTranslator 全原版后端接入实验版
====================================================

上游作者：https://github.com/HIllya51/LunaTranslator
严格固定原版：v12.1.3.9，commit 84677faeaa1e61bd7dd00b820090e9d2fe6c5142
完整上游 GPLv3 源码：随本实验 ZIP 的 LunaOriginal/UPSTREAM_FULL_SOURCE_v12.1.3.9.zip
原版程序文件：LunaOriginal/LunaTranslator_x64，原版所有文件逐字节校验，均未经修改。
新加入原版目录的 bluestar.py 是【传递坐标和文字的进程间通信插件】，不是 OCR 模型或算法。
使用原作者原封不动的：imageCutEx、ocr_run、ocrtext、CVUtils.dll、MS-SSIM、模型设置及 Qt 原版扫描线程。
蓝星原先的本地 RapidOCR/128x72 游戏连续扫描路径在本实验版本的正常运行中不调用。

首次运行
--------
1. 解压整个文件夹到与旧版不同的新路径，运行 GameTextReader/GameTextReader.exe。
2. 按 F8 或进入 F9 的区域模式时，程序会自动启动同包内的完整 LunaTranslator 原版进程。
3. 原版窗口可能出现；请在 Luna 界面检查 OCR 已启用，并设置合适的原版 OCR 模型、
   CPU/GPU 设备和识别策略。原版配置独立存放在 userconfig_bluestar 中，不触碰你原先的安装。
4. 等原版启动并加载引擎，再使用原有 F8 全屏 OCR 或 F9 切换到区域模式。
5. 在区域模式按 F11 框选范围，接入插件会调用原作者原版 OCR 区域管理与连续识别线程，
   由原版程序完成之后所有截图、帧分析、模型运行、文字去重，再将新文字交给蓝星原来的语音系统。
6. F7 控制固定区域边框显示，滚轮清空仍尽力通知原版删除区域。
7. 不要同时启动其他旧版 GameTextReader 的连续跟踪，否则两套扫描会叠加占用 CPU。

安全说明
--------
* 插件只侦听本机 127.0.0.1 端口 29380（操作命令），向 127.0.0.1:29381 发送新原文。
* 默认禁用原版 Luna HTTP 网络服务；不将截图、OCR 文字或私人语音配置上传。
* 插件只负责进程/文字传输与框坐标转换，没有自己编写或替换 OCR 算法。
* 原版用户配置和模型与 BlueStar PP-OCRv6 Small 不一定一样，不应假设识别率完全相等。
* 本版本属于独立实验，不是已经证实 CPU 降低、FPS 保持 100 的稳定版。
* 原版内置的 Qt 可视 OCR 选区与蓝星自己的边框可能仍需要实际游戏验证，
  如出现覆盖画面、CPU 暴增、文字漏识别，立刻退出实验版，使用旧版。
* 原版作者版权与 GPL-3.0 全部保留，原 Luna 的 586 个运行文件保持原样，
  只有额外添加的进程间通信插件和独立用户配置不同。
